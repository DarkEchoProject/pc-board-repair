# سوق بوردات كمبيوتر

السوق في `/market/` مخصص لبوردات الكمبيوتر واللابتوب وقطع صيانتها. لا توجد إعلانات أو بيانات تجريبية مضمنة في نسخة الموقع.

## الاستخدام

- تظهر شروط السوق وإخلاء المسؤولية قبل البحث والتصفّح وقراءة الإعلان والردود والتواصل. لا تُحمّل الإعلانات حتى الموافقة الصريحة.
- يمكن تجهيز عرض أو طلب كزائر. تسجيل الدخول الحالي مطلوب عند النشر والرد وإدارة الإعلانات.
- تحفظ مسودة الإعلان الجديد مؤقتًا في جلسة المتصفح عند الانتقال لتسجيل الدخول، وتُستعاد بالعودة إلى `?compose=1`.
- فلاتر للبيع/مطلوب، التصنيف، البحث، طرابلس، لبنان، وخارج لبنان.
- حتى 3 صور اختيارية. يحولها المتصفح إلى JPEG بأبعاد قصوى 1280 بكسل وحجم لا يتجاوز 180 KiB للصورة.
- يُظهر الإعلان السعر/الميزانية والعملة والحالة والمكان وطريقة التسليم ووسيلة تواصل يختار صاحب الإعلان نشرها.
- التفاوض والتسليم مباشرة بين الطرفين. لا توجد مدفوعات أو حجوزات داخل الموقع.
- يستطيع صاحب الإعلان تعديله أو إغلاقه أو إعادة فتحه أو إزالته. تخفي الإزالة الإعلان وصوره عن الجمهور.

## البيانات والصلاحيات

تُحفظ الموافقة لمدة 30 يومًا في ملف ارتباط HttpOnly خاص بمسارات API السوق، مرتبط برمز عشوائي محفوظ في SQLite. تتحقق واجهات الإعلانات والصور والردود من الرمز وصلاحية النسخة قبل إرجاع البيانات أو تنفيذ العمليات؛ الإدارة تبقى محمية بمفتاحها المستقل. عند تعديل الشروط يجب تحديث `MARKET_TERMS_VERSION` في `src/market.js` و`TERMS_VERSION` في `public/market/market.js` ونص النافذة في HTML وإصدار ملف JS، فتُطلب الموافقة مجددًا.

يستخدم السوق اسم الكائن `repair-market` داخل ربط `CHAT_ROOM` الحالي. لا يحتاج ربطًا جديدًا أو مفتاحًا جديدًا. تبقى غرفة الصيانة `repair-main` وعدادات الموقع في كائناتها الحالية.

يُنشئ `src/market.js` جداول SQLite الخاصة بالسوق عند أول طلب لهذا الكائن. تبقى البيانات مخزنة عند إعادة نشر كود Worker.

تتحقق `src/app.js` من جلسة المستخدم قبل تمرير هويته داخليًا. لا تُقبل رؤوس الهوية التي يرسلها الزائر. لا تعيد الواجهات العامة معرّفات الحسابات أو البريد الإلكتروني.

تُحمى عمليات الكتابة بالجلسة وصلاحية صاحب الإعلان، وفحص المصدر وحجم الطلب والصور. تستخدم الكتابة معاملات SQLite وتحقق النسخة لمنع الكتابة فوق تعديل أحدث. يمنع `requestId` تكرار المنشور أو الرد عند إعادة نفس المحاولة.

الحدود الحالية: 10 إعلانات جديدة/ساعة لكل حساب، 60 تعديلًا/ساعة، 30 ردًا/15 دقيقة، و10 بلاغات/يوم. ترجع الواجهات رسالة واضحة عند تجاوزها.

## الإدارة

قسم السوق مضاف إلى `/admin` ويستخدم `ADMIN_TOKEN` الحالي. يستطيع المدير مراجعة البلاغات والإعلانات والصور وإخفاء الإعلان وإعادته وتجاهل البلاغات. صور الإدارة تُجلب بمفتاح الإدارة وتُعاد دون تخزين مؤقت.

## المسارات

- `GET/POST /api/market/consent`
- `GET/POST /api/market/listings`
- `GET/PATCH /api/market/listings/:id`
- `POST /api/market/listings/:id/status` مع `close` أو `reopen` أو `delete`
- `POST /api/market/listings/:id/replies`
- `POST /api/market/listings/:id/report`
- `GET/HEAD /api/market/images/:id`
- `GET /api/admin/market/overview`
- `GET/HEAD /api/admin/market/images/:id`
- `POST /api/admin/market/action`

## التحقق

تحتاج اختبارات SQLite إلى Node.js 24 أو إصدار يدعم `node:sqlite`:

```powershell
node.exe --test tests/market.test.mjs tests/app-market.test.mjs
```

تستخدم الاختبارات قواعد بيانات ذاكرة مؤقتة وحسابات اختبار فقط. تشمل حفظ الصور، ملكية الإعلانات، الجلسات الموقعة، صلاحيات الإدارة، الطلبات المتكررة، البحث العربي، الإغلاق والإخفاء، وطلبات الصور HEAD/304.

تعمل معاينة الصفحة والنموذج محليًا كزائر. الحفظ الفعلي والردود يحتاجان جلسة دخول صالحة؛ إعدادات Google الحالية محفوظة في Cloudflare. نشر السوق يتبع موافقة صاحب الموقع وإجراءات Wrangler المعتادة.
