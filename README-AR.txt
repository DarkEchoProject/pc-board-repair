PC Board Repair - طريقة العمل

مسار العمل الآمن:
1) تحديث نسخة المعاينة والعمل على فرع منفصل.
2) تشغيل PREDEPLOY-CHECK.ps1 و SEO-CHECK.ps1.
3) تجربة Wrangler dry-run و dev --local.
4) بعد المراجعة والموافقة فقط: الدمج ثم DEPLOY-SITE.cmd.
5) اكتب DEPLOY عند طلب الموافقة النهائية داخل السكربت.

السكربتات التاريخية:
راجع docs/scripts.md قبل تشغيل سكربتات الاستيراد والاسترجاع والرفع.
بعضها يكتب الفهرس أو يرفع إلى GitHub أو يطلب نشر الموقع.
لا تستخدمها من نسخة المعاينة ولا أثناء عمل خط تحميل BIOS اليومي.
