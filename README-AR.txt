PC Board Repair V7 - طريقة الاستخدام السريعة

رفع الموقع الحالي:
1) افتح DEPLOY-SITE.cmd
2) انتظر حتى تظهر DEPLOY COMPLETED SUCCESSFULLY
3) افتح الموقع واضغط Ctrl+F5

إضافة بورد جديد لاحقا:
1) افتح ADD-BOARD.cmd
2) اكتب الشركة والموديل ورقم البورد.
3) عند طلب ملف ZIP/RAR اسحب الملف من مستكشف الملفات إلى النافذة ثم Enter.
4) اسحب صورة البورد أو اضغط Enter بدون صورة.
5) عند سؤال Deploy اكتب y ثم Enter لرفع الموقع مباشرة.

لا تحتاج إلى تعديل ملفات HTML يدويا.
